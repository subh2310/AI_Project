🛡️ NexusIQ: Enterprise Agentic Document IntelligenceNexusIQ is a high-performance, Agentic RAG (Retrieval-Augmented Generation) platform. Unlike standard chatbots, NexusIQ operates as an autonomous analyst that reasons over unstructured data using a hybrid architecture—combining local embeddings with high-speed inference.FeatureGenerative AI (The Engine)Agentic AI (The Brain)Primary ActionGenerates text based on a prompt.Reasons if context is sufficient; uses tools if not.Knowledge SourceInternal model weights.FAISS (Local PDF) + Tavily (Real-time Web).Logic GoalFluency and Creativity.Factuality, Multi-source Synthesis, and Tool-Use.✨ Key FeaturesHybrid Intelligence: Uses Llama-3.1-8b (via Groq) for lightning-fast reasoning and Nomic-Embed (via Ollama) for local privacy.Multi-User Sharding: Unique UUID-based FAISS indexing ensures User A’s data never leaks into User B’s session.Rate-Limit Shield: Integrated Global Thread Locking and RPM Throttling to ensure stability on shared API tiers.Autonomous Web Augmentation: The Agent automatically triggers a Tavily Web Search if the PDF does not contain the required technical details.📖 System ArchitectureNexusIQ follows a "Surgical RAG" pipeline designed for token efficiency:Ingestion & Distillation: PDF text is extracted and split into 600-token shards with a 100-token overlap (optimized for Groq's free tier).Vectorization: Local embedding via nomic-embed-text.Isolated Retrieval: Similarity Search ($k=2$) pulls precise evidence to keep the prompt size small and fast.Agentic Execution: The CrewAI Researcher agent analyzes the "Knowledge Shards."
